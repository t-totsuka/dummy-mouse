# Idle Mouse Mover

マウスの操作がしばらくないと、カーソルを少しだけ動かして元の位置に戻す Windows 用の常駐ツールです。
画面ロックやチャットツールの「離席中」表示を防ぎます。

## 動作環境

- Windows 10 / Windows 11（管理者権限は不要）
- ビルドする場合のみ: Go 1.26 以上

## ビルド

リポジトリのルートで次を実行します。`go vet` と `go test` が通ったあと、`dist\mousemover.exe` ができます。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Git Bash の場合は `./build.sh` でも同じ設定でビルドできます。

ビルドの設定: `CGO_ENABLED=0`、`-ldflags "-s -w -H=windowsgui"`（cgo なし、コンソールなし、デバッグ情報なし）

## 起動

`dist\mousemover.exe` をダブルクリックします。ウィンドウは出ず、タスクトレイに常駐します。
トレイアイコンにマウスを乗せると、現在の設定（アイドル時間と移動量）が表示されます。

### 起動オプション

| オプション | 意味 | 既定値 |
| --- | --- | --- |
| `-idle` | 操作がない状態がこの時間続いたらカーソルを動かす。Go の時間表記（例: `5m`, `90s`, `1h`） | `5m` |
| `-step` | 1 回に動かす量（px、1 以上の整数） | `10` |

例: ショートカットの「リンク先」を次のようにすると、3 分でアイドルとみなし、20px ずつ動かします。

```
C:\tools\mousemover.exe -idle 3m -step 20
```

オプションが不正な場合は、エラーのダイアログを表示して終了します（トレイには常駐しません）。

## 終了

トレイアイコンを右クリックし、「終了」を選びます。

## 動作の注意

- 操作として数えるのはマウスの入力（移動、ボタン、ホイール）だけです。キーボードの入力は数えません。
- カーソルは 上 → 右 → 下 → 左 の順に動き、元の位置に戻ります。
- 動いている途中で自分でマウスを動かすと、その周は途中でやめます。
- 管理者権限で動いているウィンドウが前面にあると、カーソルを動かせないことがあります。
